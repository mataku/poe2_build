# Runes of Aldur (Season 0.5)

Background notes for the characters played this season. Point at these instead of re-explaining the build every time.

- [Chronomancer — matachro](chronomancer/) — CoC Comet, CI / ES
- [Spirit Walker — matalker](spiritwalker/) — crit spear + companion

## Layout

```
{character}/
├── README.md        the build's axis — committed
└── considering/     open decisions — gitignored, local only
```

`README.md` records what the build is built around, not a full item-by-item breakdown. It should stay true for the whole season.

`considering/` is where the open questions live: is this weapon worth buying, which of these two amulets, what to do about the defence problem. These are working notes — they carry prices, budgets, and shortlists, all of which go stale the moment something is bought. They are gitignored, so they stay local.

When a decision actually lands, fold the conclusion into `README.md` and let the deliberation file rot.

Numbers are from the PoE2 MCP import of the poe.ninja profile; refresh them with `import_poe_ninja_url` when the character changes.
